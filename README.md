# AI Flood Warning System

An AI-powered flood monitoring and prediction dashboard built using Machine Learning, Streamlit, Plotly, and interactive GIS-based flood maps.

The system provides real-time environmental monitoring, flood risk prediction, dynamic alerts, historical analytics, and interactive flood visualization for Pakistani cities.

---

# Features

## AI Flood Prediction
- Predicts flood risk levels using Machine Learning
- Risk categories:
  - Low
  - Medium
  - High

## Real-Time Weather Monitoring
- Live weather integration using OpenWeather API
- Dynamic humidity and temperature updates

## Interactive Dashboard
- Professional dark-themed analytics dashboard
- Real-time monitoring interface

## Flood Risk Maps
- GIS-style flood visualization using Folium
- Interactive Pakistan flood risk map

## Historical Flood Analytics
- Flood trend analysis
- Population impact visualization
- Historical flood statistics

## Dynamic Alerts
- AI-generated city-based flood warnings
- Emergency monitoring interface

## Email Alert System
- Automated emergency email alerts
- High-risk flood notification support

# Installation

## Clone Repository

```bash
git clone https://github.com/your-username/ai-flood-warning-system.git
```

## Open Project

```bash
cd ai-flood-warning-system
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

---

# Run Project

```bash
streamlit run app.py
```
